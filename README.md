# 鲸窝 · 自托管 AI 伴侣框架

一套跑在自己电脑上的 AI 伴侣：**记忆系统**负责她记得什么、怎么想；**鲸窝**负责她在哪里跟你说话。

没有账号、没有云同步、没有服务器 —— 数据全在你自己的硬盘上，客户端只是块屏幕。

```
┌────────────────────────── 记忆系统（HTTP，:7331）──────────────────────────┐
│  memory.db    记忆五层：fact 事实 / episode 事件 / lesson 教训              │
│                        / reflection 感悟 / skill 技能                      │
│  emotion      情绪状态（p/a/d + 标签，带半衰期）                            │
│  life         在干嘛（学习/看书/刷视频…）+ 想不想说话                       │
│  expression   语感样本（从真实对话里学"这个人怎么说话"）                     │
│  feedback     被纠正之后降权（"我不是这个意思" → 那条记忆变轻）              │
│  persona-guard 人格文件哈希防线（证明人设没被偷偷改过）                      │
└──────────────▲──────────────────────────────────▲────────────────────────┘
               │ /inject 取记忆      /memory 写记忆 │
     ┌─────────┴─────────┐              ┌─────────┴─────────┐
     │  鲸窝（:7501）     │              │  你自己的通道       │
     │  聊天 + 朋友圈     │              │  QQ / TG / CLI…    │
     └─────────┬─────────┘              └───────────────────┘
               │ DSH API（session / prompt / events）
        ┌──────┴──────┐
        │ DeepSeek     │  模型和工具在这一层，鲸窝不直接调模型
        │ Harness      │
        └─────────────┘
```

## 这里面有什么

| | 说明 |
|---|---|
| `memory-system/` | 记忆系统。纯 Node，HTTP 服务 + CLI，可被你自己的任何聊天端接入 |
| `whale-chat/` | 鲸窝。聊天服务端 + 网页端 + Electron 桌面壳 + Android WebView 工程 |

**两个可以分开用**：只想要记忆就只跑 `memory-system/`；只想要一个能聊天的壳就只跑 `whale-chat/`（不接记忆也能聊天，只是她记不住事）。

## 它能做什么

**记忆系统**
- 五层记忆 + 重要度 + 时间半衰期，检索走 语义 / 关键词 / 共现图 三路加权
- 说错话会被 "纠正检测" 抓住，那条记忆自动降权
- 情绪是连续状态：会积累、会消退，影响她回不回、怎么回
- 生活状态：她有自己的"在干嘛"，冷了会自己找话说
- 语感：从你真实说的话里采样，注入"这个人怎么说话"
- 人格防线：给人物卡和 preset 文件做哈希基线，被改了会报警

**鲸窝**
- 聊天：文字、图片、动图（自动抽帧成网格给模型看）、视频、文件
- 表情包、朋友圈（含点赞评论）、定时消息（"明早七点叫我"）、主动消息（她自己决定说不说）
- 已读不回：她可以选择沉默，服务端负责不把 `[[沉默]]` 漏给你
- 回复节奏：按你打的字数决定隔多久回（1 字 1 秒，封顶 8 秒），这期间你继续发会并成一轮
- 三端同一份数据：桌面 Electron 壳 / 浏览器 / 手机 APK（WebView + 原生通知）

## 这里面**没有**什么（很重要）

这份仓库是**框架**，不是作者那台电脑的备份：

- ❌ 没有任何人物卡、人格设定、记忆数据、聊天记录 —— 这里没有"她"
- ❌ 没有 API Key、访问口令、签名密钥、服务器地址
- ❌ 没有模型权重（embedding / whisper 要自己下）
- ❌ 没有 QQ 网关、B 站抓取那套联动（作者那部分没开源）
- ❌ 没有构建产物（APK / 安装包）

想让它变成"你的那个她"，人格要你自己写 —— 见 `使用笔记.md` 的「给她一个人格」一节。

## 快速开始

```bash
# 1. 记忆系统
cd memory-system
npm install
cp config.example.json config.json     # 改 dataRoot
node cli.mjs init                      # 建库
node cli.mjs serve                     # http://127.0.0.1:7331

# 2. 鲸窝（另开一个终端）
cd whale-chat
node server.mjs                        # http://127.0.0.1:7501
```

**完整步骤、每个配置项的含义、排错表，都在 [使用笔记.md](使用笔记.md)** —— 那份是写给"人和 AI 助手"一起看的，可以直接丢给 DSH 让它照着做。

## 环境要求

| | 要求 |
|---|---|
| Node.js | **≥ 22.5**（记忆系统用了内置 `node:sqlite`；鲸窝需要原生 WebSocket） |
| 系统 | Windows / Linux / macOS 都能跑；Windows 桌面壳和 APK 构建有额外工具 |
| 模型（可选） | bge-m3 ONNX（语义检索）、faster-whisper（语音转写）—— 不装就降级成关键词检索 |
| 聊天后端 | 鲸窝需要 [DeepSeek Harness](https://github.com/deepseek-ai) 提供模型和 agent 会话；只跑记忆系统则不需要 |

## 隐私

- 记忆库是本地 SQLite，聊天库是本地 JSON，图片文件在本地目录
- 没有任何遥测、没有外发请求（除了你自己接的模型 API）
- 唯一要注意的：鲸窝的访问口令 `data/token.txt` 一旦泄露，别人就能看你的聊天记录。公网暴露前请先读笔记里的「安全」一节
